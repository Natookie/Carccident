# Carccident

Carccident is a Unity project for a traffic-management / road-safety gameplay loop built around an intersection, traffic lights, car spawning, scoring, upgrades, and persistence. The project configuration and scripts indicate a game prototype focused on controlling traffic flow and avoiding collisions while earning money and progressing through upgrades.

## Features

- Four-direction road intersection with lane-based spawning and turn logic
- Player-controlled traffic light toggling for straight and right-turn lanes
- Car spawning, movement, stop logic, turning behavior, and collision handling
- Pedestrian spawning and area-based movement
- Battery drain / time-pressure gameplay loop with game-over conditions
- Score calculation, money rewards, and persistent save data using PlayerPrefs
- Settings persistence for volume, graphics, and language
- UI panels for play, pause, upgrades, settings, and traffic control

## Requirements

- Unity Editor 6000.2.6f2 (matches ProjectSettings/ProjectVersion.txt)
- Unity project packages resolved via Packages/manifest.json
- A compatible Unity installation with the standard Unity packages used by the project

## Setup

1. Clone the repository.
2. Open the folder in Unity Hub.
3. Use Unity Editor version 6000.2.6f2 or a compatible 6000.x version.
4. Let Unity import and resolve the project packages.
5. Open one of the scenes under Assets/Scenes (for example, GameScene.unity) to begin working.

## How to run

- Open the project in Unity.
- Load the main gameplay scene from Assets/Scenes.
- Press Play in the Unity Editor.
- The project uses the in-scene UI and traffic-light controls rather than a separate command-line launcher.

## Project structure

- Assets/Scenes — Unity scenes including the main gameplay scene and other scene variants
- Assets/Resources/1. C# — main gameplay and management logic
- Assets/Resources/2. Art — visual art and UI assets
- Assets/Resources/3. Prefab — prefab assets
- Assets/Resources/4. Audio — sound assets
- Assets/Resources/5. Data — data/config assets
- Assets/Settings — project settings and config assets
- Packages/ — Unity package dependencies such as URP, Input System, localization, and editor utilities
- ProjectSettings/ — Unity project settings and version metadata
- UserSettings/ — editor preferences generated by Unity

## Important systems / architecture

The project is organized around a few core systems:

- GameManager: central game state, pause flow, collision tracking, game-over logic, and reward application
- CarManager and RoadSpawnerManager: spawn logic, lane setup, turn targets, and intersection layout
- CarLogic: per-car movement, braking, stop decisions, turn behavior, and collision/rage logic
- TrafficLightManager and TrafficLight: per-direction signal state and player-triggered light changes
- TrafficUI: in-scene traffic-control prompt and lane-state display
- PedestrianSpawner: object pooling and spawning of pedestrians in designated crossing areas
- SaveManager: PlayerPrefs-based persistence for money, scores, upgrade levels, volume, graphics, and language
- BatterySystem and ScoreCalculator: gameplay resource drain and end-of-run reward calculation

## Development notes

- The code uses Unity's built-in MonoBehaviour workflow, with many gameplay systems implemented as scene-attached components.
- A large portion of the project is organized under Assets/Resources/1. C# by system (Manager, GameFlow, Pedestrian, UI, Camera, Localization).
- Many editor convenience features are present, including debug controls and NaughtyAttributes-based inspector helpers.
- The repository contains third-party/editor packages and prefabs under Assets/ and Packages/; these are part of the project assets rather than a separate backend service.
